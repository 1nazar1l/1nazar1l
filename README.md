## Projects

### 🎬 MoviesSite — Movie & TV Series Catalog
A full-featured web application for cataloging movies and TV series with social network features. Users can browse films, series, and actors, leave rated comments, create custom lists, and add content to favorites.

**Key features:**
- Comment system with ratings (1–10), likes/dislikes, and private notes
- Custom user lists: Favorites, Watch Later, Watched, and user-defined lists
- Automated data population via **TMDB API** (movies, series, actors)
- Web scraping with **BeautifulSoup4** for additional data
- Admin panel for content management
- Profanity filter with multi-language support

**Tech stack:** Python, Django 5.2.6, SQLite3, TMDB API, BeautifulSoup4, Pillow, Git
